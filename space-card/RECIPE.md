# Space Card Linker Mod for Herdr

Link Herdr Spaces and worktrees to issue cards and groups (e.g. `CARD-2467`).

## Features
- Right-click any space in the sidebar to open context menu.
- Click `Link Card / Group...` (or `Card: #CARD-XXXX` to edit/change).
- Interactive dialog with existing cards from your to-do lists, plus custom ID input.
- Badge `#CARD-XXXX` displayed directly on the space row in the sidebar.
- CLI integration via `todo space [get|link <CARD>|unlink|list]`.
- Automatic card assignment when creating tasks within that space.
